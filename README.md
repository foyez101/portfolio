## Design

A "signal → system" visual identity, tying together a background in speech/signal processing with full-stack software engineering:

- **Animated loading screen** — an oscilloscope-style waveform fills in from 0–100% with cycling system-boot text before revealing the page
- **Hero animation** — a canvas-based waveform dissolving into a connected node network, running ambiently in the background
- **Typography** — Bricolage Grotesque for the hero headline, Sora for section headings, Inter for body text, IBM Plex Mono for labels and data
- **Palette** — deep navy background with electric teal and violet accents
- Scroll-triggered reveals, hover interactions, and full support for `prefers-reduced-motion`

## Tech Stack

Plain HTML, CSS, and vanilla JavaScript — no framework or build step. The canvas animations (loading screen + hero) are hand-written, and everything is a single self-contained `index.html` file, deployed via GitHub Pages.
