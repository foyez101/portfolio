Thesis · 2026Speech · NLP

Bengali Audio Transcription & Summarization with a new dataset

A pipeline that turns Bengali speech into a transcript and a short summary. Our team built a new dataset of 1,160 audio clips with verbatim transcripts and reference summaries (928 train / 116 validation / 116 test), the thesis's main contribution.

  • Fine-tuned Whisper-small: word error rate 55.0% → 17.3%, character error rate 22.6% → 6.0% on the test set
  • Fine-tuned BanglaT5 for abstractive summaries: ROUGE-L 14.5 → 25.3 over the earlier mT5-small model
  • FastAPI web app that turns uploaded audio into a transcript and summary, with pause-based audio chunking
